# 📖 MAPA OFICIAL DE PALABRAS RESERVADAS - RAMATI-Q
**Versión del Kernel:** 0.6+
**Paradigma:** Computación Cuántica Cognitiva y Lógica Difusa Nativa
**Autor:** Ing. Yoffre Itamar Arias Errays

Este documento establece el léxico oficial y exclusivo del compilador Ramati-Q. Estas palabras son el puente directo entre la lógica humana y el motor de procesamiento del núcleo. No pueden ser utilizadas como nombres de variables.

---

## 1. CONTROL DEL CICLO DE VIDA (ESTADO DEL SISTEMA)
| Palabra Clave | Función Principal |
| :--- | :--- |
| **origen** | Obligatorio. Punto de entrada. Reserva la memoria cuántica y limpia el entorno estableciendo la fase cero del script. |
| **colapsar** | Obligatorio. Finaliza la superposición computacional, cierra el ciclo y entrega la respuesta final en un archivo binario `.qbin`. |

## 2. DECLARACIÓN DE VARIABLES Y ESTADOS
| Palabra Clave | Función Principal |
| :--- | :--- |
| **variable_difusa** | Declara un dato que representa un estado de probabilidad o espectro humano (0.0 a 1.0), no un valor estático absoluto. |

## 3. OPERADORES CUÁNTICO-COGNITIVOS NATIVOS
| Palabra Clave | Función Principal |
| :--- | :--- |
| **entrelazar** | Vincula el estado de dos variables difusas a nivel cuántico (Compuerta CNOT simulada). |
| **intersecar** | Calcula la intersección lógica (mínimo) entre las probabilidades de dos variables. |
| **superponer** | Lleva un cúbit a un estado de superposición perfecta (50/50). |
| **fluctuar** | Invierte las amplitudes de probabilidad de una variable difusa. |
| **sintonizar** | Ajusta o reasigna manualmente la probabilidad de un cúbit ya existente. |
| **armonizar** | Analiza la entropía del sistema para detectar estados de `ANGUSTIA_LOGICA` o `ARMONIA_COGNITIVA`. |
| **resonar_bucle** | Ejecuta un ciclo de estabilización u homeostasis entre dos variables hasta alcanzar un delta objetivo. |

## 4. PUENTE CIBERNÉTICO / HARDWARE (Fase 0.8+)
| Palabra Clave | Función Principal |
| :--- | :--- |
| **capturar** | Absorbe datos del mundo físico a través de canales externos y los normaliza al espectro cuántico. |
| **observar** | Marca una variable específica para que su estado sea monitoreado de cara al colapso final. |
| **entrelazar_canales** | Dispara una señal eléctrica o de control desde el Kernel hacia el hardware físico conectado (ej. motores, sensores). |
| **diagnostico** | Imprime en caliente la telemetría y el estado cognitivo (probabilidades activas) de todas las variables en memoria. |

## 5. FLUJO Y LÓGICA DIFUSA
| Palabra Clave | Función Principal |
| :--- | :--- |
| **si_difuso** | Evalúa una condición basándose en el nivel de probabilidad de una variable (ej. `> 0.50`). |
| **sino** | Camino alternativo si la evaluación probabilística de `si_difuso` no alcanza el umbral. |
| **y_difuso** | Conecta múltiples condiciones difusas con una operación lógica AND. |
| **hasta** | Límite o umbral utilizado en operaciones de resonancia (`resonar_bucle`). |
