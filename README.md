## Lenguaje nativo para inteligencia cognitiva, robótica y lógica difusa

Ramati-Q es un lenguaje de programación original diseñado para sistemas inteligentes, automatización cognitiva, robótica y toma de decisiones con incertidumbre. Combina una sintaxis clara en español, un motor difuso nativo y una arquitectura pensada para ejecución autónoma.

> Ramati-Q es la cara visible del proyecto. Rust aporta la infraestructura técnica, pero la identidad, la misión y la presencia pública del ecosistema pertenecen a Ramati-Q.

---

## ¿Por qué Ramati-Q?

Ramati-Q no nace para repetir paradigmas existentes. Nace para ofrecer una base propia para programar sistemas que interpretan contexto, reaccionan con criterio y operan de manera inteligente en entornos complejos.

- Sintaxis original y legible
- Lógica difusa integrada desde el núcleo
- Enfoque orientado a robótica, automatización y control cognitivo
- Arquitectura modular y preparada para evolución
- Compilador nativo con identidad propia
- Experiencia de programación en español

## Instalación

```bash
git clone https://github.com/ITAMAR74IA/Ramati-Q.git
cd Ramati-Q
cargo build --release
```

Luego ejecuta el binario generado en la carpeta `target/release`.

---

## Ejemplo rápido

```rmq
objetivo 80.0 80.0
espectro distancia_frontal = 1.0

bucle_cognitivo 150 ->
    capturar distancia_frontal de sensor_frontal
    si_difuso distancia_frontal < 0.5 ->
        accionar giro_izquierda con 1.0
    fin_si
fin_bucle
```

Este ejemplo representa la visión del lenguaje: objetivos, espectros, decisiones difusas y ejecución cognitiva orientada a sistemas inteligentes.
